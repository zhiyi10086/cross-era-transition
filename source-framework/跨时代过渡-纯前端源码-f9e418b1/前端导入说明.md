# 《跨时代过渡》纯前端源码包

本压缩包只包含网页前端和其最小构建参照，不包含 `server/`、`drizzle/`、`storage/` 或自动化脚本。核心网页源码位于 `client/`：其中包括 HTML 入口、React/TypeScript 页面、CSS、交互逻辑、第二幕视觉素材绑定、组件与测试。

## 迁入 Manus 小组项目

1. 在小组中创建一个采用 React/Vite Web App 模板的项目。
2. 将本压缩包中的 `client/` 覆盖到目标项目根目录的 `client/`。
3. 将 `shared/const.ts` 合并到目标项目的同名文件中。此文件提供登录与基础常量引用。
4. 保留目标项目自带的 `server/`；前端的 `client/src/lib/trpc.ts` 仅将其作为类型和接口来源。若小组项目不需要 AI 学习计划功能，可把对应 tRPC 调用替换为静态逻辑或新的接口。
5. 以目标小组项目的 `package.json` 为准安装依赖；本包中的根级 `package.json`、`pnpm-lock.yaml`、`tsconfig*.json` 和 `vite.config.ts` 仅作为当前前端依赖与构建配置的参照。

## 素材路径

第二幕 DNA、数字资产与碎裂素材使用 `/manus-storage/…` 路径。迁入小组项目后，请在 `client/src/components/ActTwoVisuals.tsx` 中确认这些路径可访问；若小组项目拥有独立素材空间，请在此文件中替换为新的地址。
